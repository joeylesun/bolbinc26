Selection framework

Specify the light source from the system backwards.

Design inputWhy it mattersComponent decision
Target wavelengthMicrobial response, material transmission, and validation basis265 nm S3535 platform or selected 275 nm option
Required irradiance / doseSets source count, working distance, exposure time, and opticsSingle emitter, linear array, dense array, or custom layout
Mechanical geometryDetermines package placement, board shape, and optical coveragePackaged LED, Hex, 1×12, 5×5, or custom MCPCB
Thermal environmentOutput, wavelength, and lifetime depend on junction temperatureHeatsink, active cooling, interface material, and derating
Electrical architectureDefines current regulation, series/parallel strings, monitoring, and protectionDriver topology and connector strategy matched to the module
Production stagePrototype flexibility and production repeatability require different supportSamples, reference design, custom array, or released production configuration
Component selection

Send the application requirements—not only the desired part number.

Include wavelength, optical target, distance, geometry, flow or line speed, cooling, control interface, prototype timing, and expected annual volume.
